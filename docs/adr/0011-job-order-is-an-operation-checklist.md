# The Job Order is an operation checklist

A Job Order lists the operations to perform and the information needed to complete each step. This makes it a usable checklist for the assigned work rather than a narrative that leaves the agent to reconstruct the steps.

Consequences: Whether operation definitions come from a reusable global catalog or each order remains open; packet and validator changes are deferred.
