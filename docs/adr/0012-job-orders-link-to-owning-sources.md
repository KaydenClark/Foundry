# Job Orders link to owning sources

A Job Order links to the Workbench Contract, the actor's Clearance band, the goal, and required evidence so its assignee can reach everything needed from the order. Referencing information at its existing home avoids authority drift caused by restating it inside each packet.

Consequences: Rewriting the packet follows the governance definition correction; this pass leaves existing packets and their schema unchanged.

Provenance: owner-accepted decision, 2026-09-03; copied for the undeployed Foundry template. Instance-specific session provenance is retained separately.
