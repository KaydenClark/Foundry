# Governance policy is data with a derived view

The governance policy is stored as structured data, with any matrix rendered from that source and its conditions. Entries describe operations and their target role, authorizing Canon, and required Clearance and Job Order where applicable, avoiding permanent file classifications and a second hand-maintained authority table.

Consequences: Implementation remains deferred. The reusable global operation catalog versus per-order definitions, domain-verb mapping, cross-plane policy treatment, and missing-entry behavior remain open; completing them is not a prerequisite for this documentation correction.

Provenance: owner-accepted decision, 2026-09-03; copied for the undeployed Foundry template. Instance-specific session provenance is retained separately.
