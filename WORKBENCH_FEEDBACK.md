# Servitor Foundry - Workbench Feedback

This append-only log carries concrete lessons from operating this repository
back to whoever owns the affected surface — the Foundry harness itself, a
native Hall, or the canonical LLM Workbench. Log friction here; keep
Foundry-specific requirements, decisions, and proof in `specs/`. This is
specifically material for the Assay's read-only quality review, not a place
to record work that already has a home in a spec or the Taskboard.
